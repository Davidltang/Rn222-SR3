Overview
The Pb214 beta-emitter is one of the main background contributor in the lowER region. A good
estimation on the Pb214 rate is therefore important for every study within this region of interest (see
the notes in the reference). As Pb214 is one of the decay daughter from the Rn222 decay chain,
which also include several mono-energetic alpha-emitters in the high energy region. Since these beta-
emitters and alpha-emitters originate from the same chain, these decays are physically one-to-one
corresponding to each other minus, for instance, the plate-out contribution. For this reason, it is
possible to use the alpha rate information to set constraints on the Pb214 rate.
The goal of this analysis is to try to evaluate the alpha rate using S1only data, which should include
BiPo rates as well.

Fiducial Volume Estimation and Event Selection Systematics
ﬁducial volume
The ﬁducial volume estimation from s1only analysis essentially follow Dominick's note. The main idea
is to simply compare s1only events count to that of s1s2. The ﬁrst step is to match s1only event one-
to-one to that of s1s2; any events without s2 are ignored. Also because s1s2 doesn't quite handle
BiPo events well, those events are also cut out via s1only corrected area. The next step is deﬁning a
reference volume using s1s2 as shown in Fig.6a, whose volume should be known with an known
uncertainty. Then if we make a s1only ﬁducial volume cut, by comparing the count ratio:
(reference-volume)*(counts in reference-volume and s1only-FV)/(counts in
reference-volume),
should give us the estimated s1only FV with the uncertainty determined by Clopper-Pearson intervals
of a binary distribution (taking the larger side of the interval as the uncertainty).

Alpha Event Rate
error included
Since the rate formula is as simple as
R = count/(time*xenon_density*fiducial_volume)
The associated error contribution are
error propagation from the multi-peak ﬁt that selected the count range
Poisson for the count
Xe density of  using 0.1 mbar variation according to dashboard  and
density reference at gas/liquid transition point according to NIST
r positional error of 2cm for the reference volume (see Fig.3 from note)
z positional error of 1.5 for the reference volume (see Fig.5 from note)
the binomial error from s1only ﬁducial volume selection
the binomial error from comparing to s1s2 cut (which should have no acceptance lost) as
discussed in the “event selection” section
Notice, the deadtime  has been subtracted out from livetime  using the deadtime plugin. However,
no error is assigned to them.
