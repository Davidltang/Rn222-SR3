fuse simulations
We added to our private_nt_aux_ﬁles  a new fuse conﬁguration ﬁle for SR3. In this conﬁguration we
disable most of our detector dependent eﬀects like ﬁeld distortions, charge insensitive volumes etc.
Instead the conﬁg uses a plain homogeneous drift ﬁeld with drift velocity and longitudinal diﬀusion
taken from this paper . By default we assume a drift ﬁeld of 100 V/cm. The secondary scintillation was
updated as well. Here we assume a constant electron extraction eﬃciency of 80 % with a constant
secondary scintillation gain of 42.5 pe/e.
To run fuse simulations you must use the latest main branch of fuse  and the daq-vanilla branch of
straxen . Git clone fuse, which will automatically be the master branch, and then reference it for your
imports instead of using the container installed version.
import sys
sys.path.insert(0, '/PATH/TO/fuse')
As context you have to specify the following:
st = fuse.context.xenonnt_fuse_full_chain_simulation(
        output_folder=PATH_TO_SOME_DIRECTORY_OF_YOUR_LIKING,
        corrections_version="global_v20",
        simulation_config="sr3_dev",
        clustering_method="lineage",
        run_id_specific_config={
          "gain_model_mc": "gain_model",
          "electron_lifetime_liquid": "elife",
          "drift_time_gate": "electron_drift_time_gate",}
)
st.set_config(
    {

The parameters in set_config  ensure that no spatial corrections and the correct electron drift
velocity are used when building events. These preliminary settings can be used to study a ﬁrst rough
peaklet building and classifcation with straxen. Once we know the ﬁnal ﬁeld conﬁguration the settings
will be updated. If you want to adjust any of the parameters you have to change in addition to the
conﬁgs above the following values:
st.set_config(
    {
        "diffusion_constant_longitudinal": 2.5e-08, # Longitudinal diffusion
in units of cm²/ns.
        'drift_velocity_liquid': 0.00015,  # Set electron drift velocity in
fuse (careful in the set config above we only adjust straxen)
        'electron_extraction_yield':  0.8, # Relative electron extraction
efficiency
        's2_secondary_sc_gain':  42.5, # SE gain in pe/e
    }
)
