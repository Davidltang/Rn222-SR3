of that S2)
  run 079795: PI = 0.0056, Anode:+3.0 kV, Gate:-1.0 kV
  run 079801: PI = 0.0134, Anode:+3.0 kV, Gate:-2.0 kV
This is physically logical because for S2s with the same area(PE), the same number of photon are
released. The photons create the same number of free electrons in the liquid xenon bulk. When these
electrons are drifted to the liquid surface, for a higher extraction ﬁeld, the single electron gain and the
extraction eﬃciency are both higher, hence these electrons give higher junk area and PI value.
Compared to the order of magnitude of PI in SR0 (~0.01) and in SR1&SR2 (~0.1), current PI is similar
to SR0 PI.
